## What it does

Writes one sentence (at most 280 characters) that brings back a childhood memory to `/output/entry.txt`:

> Every time rice steams, I am seven again at Grandma's table, swinging my bare feet above the linoleum while she hums and fans the pot with a folded newspaper.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
